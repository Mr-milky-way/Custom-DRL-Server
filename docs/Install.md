## Getting Started
You are going to need to do a few things before you start installing the game patch:
- Your game folder location
- Ideally - but not needed - a backup of offline files (only if you connected to the servers pre-shutdown and have not reinstalled the game) [More on that here](#making-a-backup-of-offline-files)

You can skip this if you already have these 2 things done

### Finding Game Location
To find your games install directory if you are on the steam version of the game click on the game and head to the little gear icon on the far right of the play button. The go to Manage => Browse Local Files. This will bring you to the games install directory.

If you are on the Epic version of the game go to the 3 dots on the located on the bottom right of the game tab. Then go to Manage, and in the Installation section you will see a little folder icon just left of the Uninstall button. Click on the little folder icon and it will bring you to the games install directory.

### Making a backup of offline files
If you have connected to the games old server pre-shutdown and have not uninstalled your game you will have saved files from that. In order the back them up you need to go to your games [install directory](#finding-game-location) and then go to DRL Simulator_Data => StreamingAssets => game => storage. From there you have 2 options
- Make a backup of the whole storage

OR

- Make a backup of the offline folder

Either will work and you don't get much from backing up the whole storage.

You are now ready to install the DLL patch

## Installing the patch
If you are on windows (all other versions OS's untested) download DRLPatchWin.zip from the Releases page and unzip into the [install directory](#finding-game-location) boot up the game and now you should start connecting to the game server :)
